
Visit [discussion on astronomy stack exchange](https://astronomy.stackexchange.com/questions/13488/where-can-i-find-the-positions-of-the-planets-stars-moons-artificial-satellit) to have broader overview of possible sources of space objects data positions.

This layout computes position of space objects using SPK files (SPICE Kernel) that matches closely to JPL HORIZON. Source files are generally available on [NASA Planetary Data System archive](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/).



## Available source systems

- [JPL Planetary Data System](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/) ([details/documentation](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de430_and_de431.pdf), [wiki](https://en.wikipedia.org/wiki/JPL_Horizons_On-Line_Ephemeris_System))
    - De430.bsp (1550 - 2560 AD)
    - De431_part-1.bsp (13 200 BC -0)
    - De431_part-2.bsp (1 - 17,191 AD)
- [SPICE Kernel Data](https://naif.jpl.nasa.gov/naif/data.html) ([SPK documentation](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/FORTRAN/req/spk.html))
    - [Index of /pub/naif/generic_kernels/spk](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/)
